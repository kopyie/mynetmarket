# MyNet Market

The site is a static page. A TradingView ticker banner for seven major forex
pairs stays visible beneath the page title. The featured list and Top 50 Crypto
view retain their existing market feeds.

No Node.js server or API key is required. To publish on GitHub Pages, push
`index.html` to the repository and enable Pages. TradingView supplies the
embedded forex quotes; quote availability and delays depend on its data
providers.
