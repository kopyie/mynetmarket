# MyNet Market

The site is a static page. A TradingView banner with seven major forex pairs
and a separate U.S. Dollar Index (DXY) quote stays visible beneath the page
title. The Featured and Top 50 Crypto views retain their existing market feeds.

No Node.js server or API key is required. To publish on GitHub Pages, push
`index.html` to the repository and enable Pages. TradingView supplies the
embedded forex quotes; quote availability and delays depend on its data
providers.
