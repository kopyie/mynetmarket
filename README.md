# MyNet Market

The site is a static page. The featured list and Top 50 Crypto view retain their
existing market feeds. The Major Forex Pairs view embeds the TradingView ticker
tape for the seven major currency pairs.

No Node.js server or API key is required. To publish on GitHub Pages, push
`index.html` to the repository and enable Pages. TradingView supplies the
embedded forex quotes; quote availability and delays depend on its data
providers.
